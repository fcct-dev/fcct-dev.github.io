# fcct-dev.github.io — кореневий сайт

Заготовка. **Репозиторію ще не існує** — його треба створити, і назва має бути
рівно `fcct-dev.github.io`, інакше GitHub Pages віддасть вміст не з кореня.

## Навіщо

`app-ads.txt` мусить лежати точно за адресою `https://<домен>/app-ads.txt` —
без жодного шляху. Краулер Google не піде ні в підкаталог, ні за редиректом.

Наявний репозиторій `fcct-dev/legal` — це *project pages*, він публікується за
`https://fcct-dev.github.io/legal/`. Покласти файл туди означає віддати його за
`/legal/app-ads.txt`, де його ніхто не шукатиме. Корінь `fcct-dev.github.io`
обслуговує окремий репозиторій — *user pages*, названий як домен. Це правило
GitHub, не вимога AdMob.

## Що всередині

| файл | навіщо |
|---|---|
| `app-ads.txt` | підтверджує, що рекламу від імені цього застосунку продає саме наш AdMob-акаунт |
| `index.html` | щоб корінь не віддавав 404; лінки на наявні сторінки в `/legal/` |

Рядок в `app-ads.txt`:

```
google.com, pub-8089768929534461, DIRECT, f08c47fec0942fa0
```

`pub-8089768929534461` — наш publisher id (звірити з `ADMOB_APP_ID`,
`test-call/autoload/ads_service.gd:93`). `DIRECT` = продаємо напряму, не через
посередника. `f08c47fec0942fa0` — сталий ідентифікатор Google як центру
сертифікації, однаковий у всіх видавців.

## Як публікувати

1. Створити на GitHub публічний репозиторій **`fcct-dev.github.io`** в акаунті `fcct-dev`.
2. Залити вміст цієї теки в гілку `main`.
3. Settings → Pages → Source: `main` / `(root)`.
4. Перевірити: `curl -s https://fcct-dev.github.io/app-ads.txt` має віддати рядок вище.
5. У лістингу Play вказати `https://fcct-dev.github.io` як **вебсайт розробника** — AdMob шукає файл саме за доменом із лістингу.

Перевірка на боці AdMob займає до доби. До неї застосунок лишається
неверифікованим, а `USE_LIVE_AD_UNITS` має лишатись `false`.

## Застереження

`github.io` є у Public Suffix List, і з такими хостами краулери app-ads.txt
історично іноді збоїли. Для тестового етапу цього достатньо; перед релізом із
реальними грошима надійніше перевести сайт на власний домен (у чеклісті вже
фігурує `fcctstudio.com`) і оновити поле в лістингу.
